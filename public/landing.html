Quick start

Verify in 10 lines

Install the SDK, create an invoice, and verify a transaction hash against the USDC contract on Base.

TypeScript · basereceipt SDK 
import { createInvoice, verifyPayment, MemoryClaimStore } from "basereceipt";

// 1. Create an invoice (10 cents USDC, expires in 15 min)
const invoice = createInvoice({
  recipient: "0xYourWalletAddress",
  amountUsdc: "0.10",
  network: "base-sepolia",   // or "base-mainnet"
});

// 2. Payer sends USDC on Base. You receive the tx hash.
const store = new MemoryClaimStore();   // Use SupabaseClaimStore in prod
const result = await verifyPayment(invoice, "0xabc123...", { claimStore: store });

// 3. Check result
if (result.status === "confirmed" || result.status === "overpaid") {
  console.log("✓ Payment verified", result.paidAtomic);
  // Grant access — status is read from the chain, never fabricated
}
Live demo

Try the x402 demo endpoint

This endpoint costs 0.10 USDC on Base Sepolia. Pay, present the tx hash, and receive the response.

How it works

  1. Call GET /api/demo/quote — receive HTTP 402 with invoice details
  2. Get test USDC from faucet.circle.com (select Base Sepolia)
  3. Send exactly 0.10 USDC to the recipient address shown in the 402 response
  4. Copy the transaction hash from Sepolia Basescan
  5. Call GET /api/demo/quote?invoiceId=...&txHash=0x... — receive the verified response

Transparency

What BaseReceipt does NOT do

  • Does not hold or move funds — non-custodial by design
  • Does not store private keys — read-only RPC calls only
  • Has not been audited — use in production at your own risk
  • Does not involve smart contracts — verifies standard ERC-20 transfers
  • Does not fabricate data — empty state when there is no real data
  • Does not support chains other than Base mainnet and Base Sepolia
