What BaseReceipt is:

  • An open-source TypeScript SDK and verification service.
  • Reads public on-chain ERC-20 Transfer logs via Base RPC nodes.
  • Protects against duplicate payment replay attacks using a ClaimStore.
  • Provides native HTTP 402 challenge negotiation for autonomous agents.

What BaseReceipt is NOT:

  • Not a custodian: never touches, routes, holds, or pools your funds.
  • Not a wallet: never requests or stores private keys or seed phrases.
  • Not audited: open-source software provided as-is under the MIT license.
  • Not a custom smart contract: reads official Circle USDC transfers only.

// Autonomous agent payment flow using viem on Base Sepolia
import { createWalletClient, http, parseAbi } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { baseSepolia } from "viem/chains";

const account = privateKeyToAccount(process.env.TEST_WALLET_PRIVATE_KEY);
const client = createWalletClient({ account, chain: baseSepolia, transport: http() });

// 1. Request endpoint → Receive 402
const res402 = await fetch("http://localhost:8080/api/demo/quote");
const challenge = await res402.json();

// 2. Pay USDC on Base Sepolia
const txHash = await client.writeContract({
  address: "0x036CbD53842c5426634e7929541eC2318f3dCF7e",
  abi: parseAbi(["function transfer(address to, uint256 amount) returns (bool)"]),
  functionName: "transfer",
  args: [challenge.payment.recipient, BigInt(challenge.payment.amountAtomic)],
});

// 3. Retry with proof → 200 OK
const res200 = await fetch(
  `http://localhost:8080/api/demo/quote?invoiceId=${challenge.invoiceId}&txHash=${txHash}`
);
console.log("Result:", await res200.json());
