Developers

Verify in 10 lines of TypeScript

Integrate the lightweight, zero-dependency SDK into any Node.js, Next.js, or Express application.

sdk-example.ts Base SDK 
import { createInvoice, verifyPayment, MemoryClaimStore } from "basereceipt";

// 1. Generate an invoice (10 cents USDC on Base Sepolia)
const invoice = createInvoice({
  recipient: "0xYourWalletAddress...",
  amountUsdc: "0.10",
  network: "base-sepolia", // or "base-mainnet"
});

// 2. Verify incoming transaction hash against the official USDC contract
const claimStore = new MemoryClaimStore(); // or SupabaseClaimStore
const result = await verifyPayment(invoice, "0xTxHash...", { claimStore });

// 3. Grant instant access upon confirmation
if (result.status === "confirmed" || result.status === "overpaid") {
  console.log("✓ Verified on Base!", result.paidAtomic);
}

Honesty & Limits

What BaseReceipt does NOT do

Transparent engineering: knowing system boundaries is critical for secure payment integration.

  • Does not hold or escrow funds (100% peer-to-peer)
  • Does not store or request private keys
  • Has not been third-party audited (MIT License)
  • Does not invent custom smart contracts
  • Does not fabricate data or metrics
  • Does not support non-Base chains
