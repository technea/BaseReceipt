How BaseReceipt Verifies Without Custody

1
🧾

Invoice Created

Merchant server calls createInvoice() specifying amount in USDC, recipient wallet address, and expiry.

2
📲

P2P Transfer

User or AI Agent pays directly from their wallet (Coinbase/Base) to the merchant wallet on Base. Funds never touch BaseReceipt.

3
🔎

Base RPC Query

BaseReceipt reads receipt from native Base nodes. Inspects Transfer event emitted by the verified Circle contract.

4
✅

Claim & Receipt

Deduplicates against ClaimStore to eliminate replay attacks. Returns cryptographic confirmation and fires signed webhook.

🔒

Strict Non-Custodial

BaseReceipt never holds, pools, or forwards tokens. We never ask for or store private keys, completely removing custodial risk.

Official Circle USDC

Hardcoded verification against official Circle contracts on Base Mainnet (0x8335...) and Sepolia (0x036C...). Zero counterfeit token risk.

Verify with 10 lines of TypeScript

Install the basereceipt package and verify payments in any Node.js, Express, or Next.js app.

index.ts — BaseReceipt SDK Base Sepolia & Mainnet 
import { createInvoice, verifyPayment, MemoryClaimStore } from "basereceipt";

// 1. Generate an invoice for 0.10 USDC on Base Sepolia
const invoice = createInvoice({
  recipient: "0xYourWalletAddress...",
  amountUsdc: "0.10",
  network: "base-sepolia", // or "base-mainnet"
});

// 2. Verify incoming transaction hash directly on Base RPC
const claimStore = new MemoryClaimStore(); // or SupabaseClaimStore
const result = await verifyPayment(invoice, "0xTxHash...", { claimStore });

// 3. Grant access upon verified on-chain confirmation
if (result.status === "confirmed" || result.status === "overpaid") {
  console.log("✓ Payment Verified on Base!", result.paidAtomic);
}
