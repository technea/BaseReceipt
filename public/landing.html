Architecture Blueprint

How BaseReceipt Verifies Without Custody

1

Invoice Created

Merchant or x402 AI Agent calls createInvoice() specifying amount, recipient address, and expiry.

2

P2P Transfer

Payer transfers USDC directly from their self-custody wallet to the merchant's address on Base.

3

Base RPC Query

BaseReceipt queries the transaction receipt and filters official Circle Transfer topics via read-only Base RPC.

4

Claim & Webhook

Prevents replay attacks via ClaimStore, returns confirmation receipt, and triggers HMAC-SHA256 webhooks.

Step 1: Cryptographic Invoicing

Invoices are created with precise atomic units (6 decimals for USDC) and an immutable expiration timestamp.

True Non-Custodial

BaseReceipt never touches, routes, or pools user funds. We never ask for or store private keys, completely eliminating custodial liability.

Official Circle Contracts

Hardcoded on-chain validation against Circle's verified USDC contract on Base Mainnet (0x8335...) and Sepolia (0x036C...).

x402 & Agent Ready

Native HTTP 402 challenge negotiation and machine-readable Bazaar catalog (/.well-known/x402-bazaar.json) for AI agents.

Verify in 10 lines of TypeScript

Integrate the lightweight, zero-dependency SDK into any Node.js, Express, or Next.js app.

verification-demo.ts Base Sepolia & Mainnet 
import { createInvoice, verifyPayment, MemoryClaimStore } from "basereceipt";

// 1. Generate an invoice for 0.10 USDC on Base Sepolia
const invoice = createInvoice({
  recipient: "0xYourWalletAddress...",
  amountUsdc: "0.10",
  network: "base-sepolia", // or "base-mainnet"
});

// 2. Verify incoming transaction hash directly on Base RPC
const claimStore = new MemoryClaimStore(); // or SupabaseClaimStore in prod
const result = await verifyPayment(invoice, "0xTxHash...", { claimStore });

// 3. Grant access upon verified on-chain confirmation
if (result.status === "confirmed" || result.status === "overpaid") {
  console.log("✓ Verified on Base!", result.paidAtomic);
}
