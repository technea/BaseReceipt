Architectural Principles

Engineered for Autonomous Trust

Six foundational architectural pillars that make PayGuard a dedicated pre-flight security gateway for AI agents.

Zero-Custody Boundary

PayGuard never requests, stores, or logs wallet seed phrases, private keys, or passwords. Strictly non-custodial by design.

SSRF-Resistant URL Parsing

Evaluated purely in-memory via static lexical parsing. PayGuard does not fetch or ping target URLs during static analysis, preventing internal SSRF probes.

Punycode Sentinel

Detects Internationalized Domain Name (IDN) homoglyph attacks that use identical-looking Cyrillic or Greek characters to deceive autonomous agents.

x402 Protocol v2 Ready

Built for the x402 open payment protocol specification, supporting pre-flight evaluation of atomic payment limits and chain IDs.

Privacy-Safe Redaction

All passwords, session tokens, reset keys, and high-entropy path segments are automatically redacted before any external threat intelligence lookup.

Low-Overhead Execution

Pure JavaScript implementation with zero heavy native dependencies. Evaluates URLs and policies in milliseconds locally in-process.

Frequently Asked Questions

In Unicode, letters from different alphabets look identical to Latin letters. For example, the Cyrillic letter "а" (U+0430) looks identical to Latin "a" (U+0061). An attacker can register pаybox.sh (encoded as xn--pybox-7qa.sh) to trick an AI agent into sending crypto to an impersonator. PayGuard decodes Punycode and inspects character sets, flagging any domain spoof immediately.
Server-Side Request Forgery (SSRF) happens when a server fetches a URL provided by an untrusted party, potentially allowing attackers to access internal cloud metadata endpoints (like AWS 169.254.169.254) or internal networks. PayGuard parses URLs purely in-memory using static algorithms and never initiates an outbound network connection to the target URL.
x402 is an open standard that revives the native HTTP status code 402 Payment Required. It allows AI agents and digital software to pay for APIs and services automatically using crypto micropayments without needing human card entry. PayGuard acts as the safety firewall for x402 transactions.
If an agent passes a URL that contains private tokens or query keys (such as ?token=xyz or /reset/12345), PayGuard's Privacy Redaction engine detects high-entropy strings and sensitive words, replacing them with [REDACTED] before any threat intelligence queries occur.
